# Foundation conventions

Requirements authority: root Plan.md, Module.md, Prototype.md, Database.md. Review and backlog: [foundation-review.md](foundation-review.md).

Use one modular Laravel monolith. `app/Actions/{Domain}` owns business transactions; `app/Services` owns reusable domain/infrastructure work; `app/Policies` combines permission/scope/ownership; `app/Http/Requests` validates HTTP boundaries; `app/Livewire/{Admin,Rider,Account}` orchestrates server-rendered interactions. Components call actions/services rather than embedding workflow logic in views or routes. Introduce domain subdirectories as functionality arrives, without an empty class for every future table.

`resources/views/layouts` provides Admin and Rider shells; `components` contains shared design-system inputs/buttons/feedback; `livewire` contains screen views. Alpine comes from Livewire; do not install a second runtime. Tailwind 4 uses CSS-first configuration and locally available system fonts.

`database/migrations` contains executable, dependency-ordered foundation DDL and exact package-owned migrations (Spatie/Pulse). `database/seeders` has reference/permission bundles without accounts; the explicitly invoked BrowserTestSeeder is restricted to isolated `*_e2e` local/test databases. Models use bigint primary keys and generated UUID v7 public route keys; public IDs never substitute for policies. All business timestamps are UTC/timestamptz. Names and contacts remain encrypted when introduced; no plaintext searchable PII schema is added by convenience.

Foundation tables: reference_values, staff, users, clients, user_client_scopes, audit_logs, outbox_events, processed_events, notifications; Spatie roles/permissions/three pivots; framework reset tokens/failed_jobs/job_batches; Pulse package tables. M13 adds debtors, contacts, addresses, customer_categories and customer_category_assignments with same-client constraints and preserved history. See Database.md's catalogue for future account/property/party/batch/import dependencies and [customer-management.md](customer-management.md) for the implemented boundaries.

AuditWriter accepts only redacted metadata keys. Sensitive actions append audit in the same PostgreSQL transaction. AuditLog rejects mutation and PostgreSQL rejects direct update/delete; production runtime roles must additionally lack schema/TRUNCATE/audit update/delete rights. Use a separate migrator. Outbox persistence/dedupe tables are present; real dispatch and reconciliation handlers ship with the first queued business module, not a fictitious catch-all handler that drops unknown events.

Redis queues use `after_commit` and retry_after=180 seconds; workers must time out earlier (120 seconds suggested). Dedicated queues are default/imports/exports/email/whatsapp/webhooks/media. Local Sail uses one durable noeviction Redis service. Production must separate queue and cache services/policies. Private S3 is configured without credentials; quarantine/scanning/authorization and document metadata arrive before enabling uploads.

Pulse routes require authenticated, active users and monitoring.view even locally. Recording is disabled pending privacy/retention review. Sentry has no DSN by default and sends only a minimal sanitized incident signal if enabled; request/exception/body/SQL/breadcrumb data are withheld. CloudWatch infrastructure logging and AWS IAM/region/domain/provider activation belong to the deployment phase. Application logs remain restricted and must not receive raw customer payloads in later modules.

GitHub is canonical; GitLab is a read-only mirror. The CI template runs only protected refs and verifies its SHA against the configured protected GitHub main branch. Set GITHUB_CANONICAL_REPOSITORY as a protected trusted URL and require GitHub reviews/branch protection before activation. No remote URL, token, mirror, deployment or branch protection was provisioned by this increment. Production image digests, static analysis, container scanning, signing, AWS OIDC and deploy/approval jobs remain Phase 7/launch work. CI itself remains unexecuted until a runner/mirror is configured.
